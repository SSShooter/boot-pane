
## 2026-11-03 GitHub Actions 全平台发布流水线

- 新增 `.github/workflows/release.yml`：workflow_dispatch 手动触发，三阶段（validate → build matrix → release）。
- 流程约束：触发前必须在 CHANGELOG.md 写好 `## vX.Y.Z` 条目；工作流校验版本格式、changelog 条目存在、tag 未占用；构建完成后 softprops/action-gh-release 打 tag 并以 changelog 段落作为 release body。
- 产物：Windows amd64/arm64（NSIS 安装包 + 便携 exe）、macOS universal dmg、Linux AppImage/deb/rpm；版本号由 CI 注入（info.json / Info.plist / nfpm.yaml）。
- 顺带修了两个阻塞打包的模板 bug：`build/darwin/Info.plist` 的 CFBundleExecutable=bootpane.exe → bootpane（否则 .app 无法启动）；`build/linux/nfpm/nfpm.yaml` 里残留的 bootpane.exe 命名 → bootpane。
- 关键环境事实：wails v3.0.0 默认 Linux 栈是 GTK4 + WebKitGTK 6.0（Ubuntu 24.04+），CI 装 libgtk-4-dev libwebkitgtk-6.0-dev；AppImage 工具需 APPIMAGE_EXTRACT_AND_RUN=1。
